Política de Privacidade — Agenda TI Para Publisher

Última atualização: 16 de novembro de 2026

Esta Política de Privacidade descreve como o aplicativo Agenda TI Para Publisher, usado para publicar conteúdo no canal Agenda TI Pará, trata informações. Levamos a privacidade a sério. Dúvidas podem ser enviadas para agendatipa@gmail.com.

1. Quais dados são coletados

O aplicativo não coleta dados pessoais de terceiros e não exige cadastro público. Ele opera a partir da máquina do próprio responsável pelo canal.

2. Dados do Google e dos Serviços de API do YouTube

O aplicativo Agenda TI Para Publisher utiliza os Serviços de API do YouTube para publicar vídeos originais no canal do próprio responsável e para ler as estatísticas desse mesmo canal.

  • O acesso aos dados do Google/YouTube ocorre somente após autorização expressa do titular da conta, por meio do fluxo de autorização OAuth 2.0.
  • Ao utilizar nossos serviços, você concorda em ficar vinculado aos Termos de Serviço do YouTube, disponíveis em https://www.youtube.com/t/terms.
  • A Política de Privacidade do Google está disponível em http://www.google.com/policies/privacy.
  • Dados acessados por meio das APIs do Google/YouTube: nome e identificador do canal do titular, metadados dos vídeos publicados pelo próprio canal e estatísticas do próprio canal (YouTube Analytics API).
  • Não acessamos, coletamos, armazenamos nem compartilhamos dados de terceiros.
  • Não criamos métricas derivadas nem combinamos dados obtidos do YouTube com dados de outras fontes.
  • O token de autorização é armazenado localmente no equipamento do responsável e não é compartilhado com terceiros.
  • O uso das informações recebidas das APIs do Google está em conformidade com a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado (Limited Use).

3. Como os dados são utilizados

As informações são usadas exclusivamente para operar o canal: publicar os vídeos do próprio responsável, agendar publicações, responder comentários e acompanhar métricas do próprio canal.

4. Compartilhamento

Não vendemos nem compartilhamos dados com terceiros. Não há uso de dados do YouTube para publicidade.

5. Segurança e retenção

O token de autorização fica restrito ao responsável, armazenado localmente. Mantemos dados apenas pelo tempo necessário às finalidades acima.

6. Seus direitos: revogação e exclusão

Você pode revogar o acesso a qualquer momento em https://myaccount.google.com/permissions. Também pode solicitar a exclusão dos seus dados pelo e-mail agendatipa@gmail.com; o pedido será atendido em até 30 dias.

7. Mudanças nesta Política

Esta Política pode ser atualizada; a data de última atualização será revisada. O uso continuado indica concordância.

8. Contato

Dúvidas sobre esta Política de Privacidade podem ser enviadas para agendatipa@gmail.com.
